# OMEGA AI

**Omi**, ton compagnon d'intelligence artificielle par OMEGA : un petit robot chaleureux qui discute de tout,
se souvient de toi et peut piloter ton OmegaDMX.

## Installer

1. Télécharge `OMEGA-AI_x.y.z_x64-setup.exe` dans la [dernière version](https://github.com/Alexh2807/OMEGA-AI-releases/releases/latest).
2. Lance-le (installation pour ton compte Windows, sans droits administrateur).
3. Connecte-toi avec ton compte OMEGA, le même que dans OmegaDMX.

Les mises à jour s'installent ensuite toutes seules : OMEGA AI vérifie à chaque ouverture s'il existe une nouvelle version.

## Confidentialité

Tes conversations et les souvenirs d'Omi restent sur ton PC. Ils ne sont envoyés au serveur OMEGA que le temps
de te répondre, et n'y sont pas conservés.

## Configuration

Windows 10 ou 11 (64 bits), connexion Internet, un compte OMEGA (https://omegasud.fr).
